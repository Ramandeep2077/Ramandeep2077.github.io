# Ramandeep Singh – Portfolio

Personal portfolio website of Ramandeep Singh, backend software engineer and MS Computer Science student at Northeastern University.

**Live site:** https://ramandeep2077.github.io

## About

A single-page portfolio built with plain HTML and CSS. No frameworks, no build step, and no JavaScript dependencies.

- Responsive layout for desktop and mobile
- Automatic light and dark mode based on system settings
- Accessible keyboard focus styles and reduced-motion support

## Run locally

Clone the repository and open `index.html` in any browser:

```bash
git clone https://github.com/Ramandeep2077/Ramandeep2077.github.io.git
cd Ramandeep2077.github.io
open index.html   # or double-click the file
```

## Use this as a template

You're welcome to fork this repository and adapt it for your own portfolio. Replace the content in `index.html` with your own details. Please don't reuse my personal information.
